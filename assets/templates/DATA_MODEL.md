## 비HTTP 입력 계약

{{저장에 연결되는 파일 입력 등이 있을 때만 형식·필드 대응·검증 조건을 한 번 정의한다. HTTP 요청은 OpenAPI가 소유하므로 복사하지 않는다. 이해에 필요한 최소 입력 예시만 여기에서 제공하고 같은 구조의 값 변형을 여러 건 나열하지 않는다. 해당 입력이 없으면 이 절은 생략한다.}}
