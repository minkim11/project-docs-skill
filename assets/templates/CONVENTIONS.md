## 테스트 판정 기준

- 주요 동작·경계·실패 조건의 기대 결과는 현재 REQ/AC·기술 계약의 해당 항목이나 적용 버전·절을 식별할 수 있는 외부 기준에서 도출한다. 근거 식별자는 테스트 또는 공용 fixture 가까이에 남기고 같은 근거는 공유 위치에 한 번만 기록한다. 테스트 입력의 출처와 기대 결과를 정당화하는 근거를 구분한다.
- 검증 대상인 구현 로직을 호출하거나 그대로 옮겨 기대값을 계산하지 않는다. 근거에서 별도로 확인한 예시 값이나 불변조건으로 판정한다. 테스트 준비·공통 assertion을 공유하는 것 자체는 금지하지 않는다.
- 실제 응답·스냅샷을 기준으로 채택할 때는 계약과 대조해 올바른 결과인지 검토한다. 재현에 필요한 시스템·버전·입력 조건만 식별하고 비밀값·개인정보는 제거한다. 현재 구현의 출력이라는 사실만으로 정답으로 삼지 않는다.
- 기준이 없거나 충돌하면 기대 결과를 추측해 확정하지 않고 가정·영향받는 검사·필요한 결정을 보고한다. 해당 검증을 완료로 보고하지 않는다.
- 기대값을 변경할 때는 근거가 되는 요구·계약 변경이나 기존 기대값의 오류를 확인한다. 테스트를 통과시키기 위해 실제 출력으로 기대값을 덮어쓰지 않는다.
